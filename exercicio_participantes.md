# Exercício: analisar dados com um assistente de IA

**AgroNet Forward · AI Insights for Agro**

Vamos usar um assistente de IA generativa (por exemplo, Claude, ChatGPT ou Gemini) para analisar uma folha de
cálculo de vendas de uma PME agroalimentar **fictícia**. O ficheiro é `producao_vendas.csv`.

> ⚠️ **Privacidade.** Use **apenas** este ficheiro de exemplo. Não carregue para estas ferramentas dados reais
> da sua empresa (clientes, preços, contratos) sem antes verificar as condições de utilização e proteção de dados.

## Passos
1. Abra o assistente de IA da sua preferência e carregue o ficheiro `producao_vendas.csv`.
2. Peça primeiro uma **descrição do ficheiro** (colunas, número de linhas, valores em falta, duplicados).
3. Faça as três perguntas abaixo.
4. **Verifique** cada resposta (ver a secção "Como verificar").

## As três perguntas
1. **Qual foi a receita total de cada ano (2023, 2024, 2025)?**
2. **Qual é o produto com melhor margem percentual** (receita − custo) / receita?
3. **Que canal de venda cresceu mais entre 2023 e 2025?** Peça também um gráfico.

## Como verificar (a parte mais importante)
- Pergunte: *"Que passos fez para chegar a este número? Mostre o código ou o cálculo."*
- Pergunte: *"Encontrou algo estranho nos dados antes de calcular (duplicados, valores em falta,
  nomes inconsistentes, valores impossíveis)? Como os tratou?"*
- Escolha **um** valor e confirme-o à mão (por exemplo, no Excel, com uma tabela dinâmica).
- Compare com um colega: obtiveram os mesmos números? Se não, porquê?

## Para pensar
- A IA avisou-o sobre problemas nos dados, ou calculou "como se estivesse tudo bem"?
- Que decisão **de gestão** tomaria com estas respostas? Que risco teria se o número estivesse errado?
